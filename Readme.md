# PhishGuard 
**Author:** Parth Pardeshi | IIT Guwahati

PhishGuard is a real-time phishing detection system. It operates as a browser extension backed by an asynchronous Python backend, bringing Enterprise Security Operations Center (SOC) capabilities directly to the end-user.

## Tech Stack
* **Target Sensor:** Custom Google Chrome Extension
* **Backend API:** Python / FastAPI
* **Machine Learning:** Scikit-Learn / XGBoost
* **Forensics:** WHOIS Domain Age Tracking
* **SOC Dashboard:** React.js / Tailwind CSS
